## 1. Sobre o projeto

Este trabalho consiste no desenvolvimento de um banco de dados completo para um Sistema de Alocação de Quadras e Espaços Esportivos da UFOP, dando continuidade ao Trabalho Prático I (TP01), no qual foi desenvolvida a modelagem conceitual por meio de um esquema Entidade-Relacionamento Estendido (ERE).

O sistema tem como objetivo gerenciar os espaços esportivos dos campi da Universidade Federal de Ouro Preto, permitindo o controle de usuários, organizações, modalidades esportivas, horários de funcionamento, agendamentos, participantes, bloqueios e chamados de suporte.

## 2. Objetivos

O TP02 tem como objetivo revisar a modelagem desenvolvida no trabalho anterior, realizar seu mapeamento para o modelo relacional, implementar fisicamente o banco de dados e desenvolver uma versão inicial do sistema para interação com os dados armazenados.

O projeto contempla a documentação dos requisitos, a elaboração dos esquemas ERE e relacional, a implementação das tabelas e restrições de integridade, a inserção de dados e o desenvolvimento de uma aplicação com, no mínimo, quatro consultas e duas operações de atualização (UPDATE e/ou DELETE).
